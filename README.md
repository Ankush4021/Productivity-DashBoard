# 🚀 Productivity Dashboard

An all-in-one **Productivity Dashboard Web App** designed to help users stay focused, organized, and motivated throughout the day.  
This dashboard combines essential productivity tools like **To-Do List, Pomodoro Timer, Daily Planner, and Motivational Quotes** in one clean and modern interface.

---

## 🌟 Features

### 📝 To-Do List
- Add, delete, and manage daily tasks
- Mark tasks as completed
- Data stored using **Local Storage**

### ⏱️ Pomodoro Timer
- Focus timer based on the Pomodoro technique
- Helps improve concentration and productivity
- Simple and distraction-free UI

### 📅 Daily Planner
- Plan your day effectively
- Organize tasks and priorities
- Easy-to-use layout

### 💬 Motivational Quotes
- Inspiring quotes to keep you motivated
- Clean visual presentation

### 🌦️ Weather & Time Dashboard
- Live date & time display
- Current location weather information
- Temperature, humidity, wind & condition display

### 🎨 Theme Toggle
- Light/Dark theme support
- Smooth UI experience

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **DOM Manipulation**
- **Local Storage API**
- **Weather API**
